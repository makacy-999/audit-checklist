# 审计应对 Check list

客户审计（第一天日程 + 附件文件清单）的逐项核对清单，供内部质量管理人员分发、跟踪、消项。

## 使用流程（多人协作）

1. **选姓名**：打开页面先选自己的姓名。姓名决定你能改哪些条目。
2. **只改自己的**：只能修改「责任人」里包含自己的条目。
3. **改完导出**：点「导出 CSV」，把文件发给质量管理人员。
4. **管理员汇总**：马宏宇以管理员身份进入，用「导入合并」把各人的 CSV 合进总表。

## 权限规则

| 角色 | 能做什么 |
|---|---|
| 未选姓名 | 全部只读浏览 |
| 普通成员 | 只能改责任人包含自己的条目；**已被他人改过的记录自动变为只读**（可看不可改） |
| 管理员（马宏宇 + 口令） | 修改全部条目、清除任意记录（含他人）、导入合并 CSV、清空数据、清空日志 |

管理员口令在 `index.html` 顶部 `ADMIN_CODE`（当前 `8888`），可自行修改。

> **注意**：这是纯静态页面，权限靠前端控制，用于**防止误改和留痕**，无法做到强制安全隔离。
> 数据存在各人浏览器 localStorage，**换设备不共享**，所以必须走「各自导出 → 管理员合并」的流程。

## 变更留痕

状态、备注、责任部门的每一次改动都会记录 **操作人 + 时间**，写入「变更日志」页，可导出 CSV 作为审计留痕证据。
管理员的清除、导入操作同样记日志（标注「（管理员）」）。

## 三个入口

| 文件 | 用途 |
|---|---|
| `index.html` | 网页版，双击即可打开。身份权限、变更留痕、搜索筛选、进度统计、按责任人派工、打印存 PDF、导出/导入 CSV |
| `审计应对Checklist.xlsx` | 离线版。Sheet① 逐项核对（主控，含更新人/更新时间列），Sheet② 按责任人派工，Sheet③ 使用说明 |
| `_build/` | 生成脚本（`data.py` 数据源 + `build.py` 生成器），改完数据重跑即可重新生成上面两个文件 |

## 处理原则

- **原文不动**：审计主题的中英文描述、条目顺序均照录自 Excel 源文件，未作改写。
- **只做三件事**：① 按审计模块分类；② 把「准备资料」里的 ①②③ 拆成可单独勾选的核对项；③ 补责任部门。
- **责任部门为推断值**：源文件只给了人名。部门是按每人承担的工作推断预填的，在网页上点开即可直接改，改完存本机。
